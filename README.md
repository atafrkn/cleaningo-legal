# Cleaningo — legal pages

Cleaningo iOS uygulamasının gizlilik politikası ve kullanım koşulları.
GitHub Pages ile yayınlanır; App Store Connect bu sayfaların URL'lerini ister.

- `privacy.html` — Gizlilik Politikası / Privacy Policy (TR + EN)
- `terms.html` — Kullanım Koşulları / Terms of Service (TR + EN)
- `index.html` — basit bir giriş sayfası
